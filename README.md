# Formative Assessment 1, Distance between two points

## Description
My program solved for the distance between two points after the users input two pairs of (x and y).

## How to Run
1. Open the program.
2. Run the program.
3. Enter the required values.

## Input Needed
- The first x value
- The first y value,
- The second x value
- The second y value

## Sample Output
The distance between points (2,3), and (7,8) is 7.07
